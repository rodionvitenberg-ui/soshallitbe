# lusion-home

Next.js (App Router) shell for a local educational clone of the **Lusion** homepage, driven by their production engine, CSS, and assets.

## Commands

| Command | Action |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Dev server at http://localhost:3000 (patches engine first) |
| `npm run build` | Production build (patches engine first) |
| `npm start` | Serve the production build |
| `npm run patch-engine` | Re-apply vendor → `public/_astro/engine.js` |

See [NOTES.md](./NOTES.md) for architecture and what to edit.
